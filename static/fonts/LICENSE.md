# Fontes embarcadas

Os quatro arquivos `.woff2` desta pasta são subconjuntos latinos de duas famílias
licenciadas sob a **SIL Open Font License 1.1**, que permite uso, redistribuição e
embarque em produto — inclusive comercial — desde que a licença acompanhe os arquivos.
É por isso que este aviso existe.

| Arquivo | Família | Autoria | Licença |
|---|---|---|---|
| `oswald-500.woff2`, `oswald-600.woff2` | Oswald | Vernon Adams, Kalapi Gajjar, Cyreal | [OFL 1.1](https://openfontlicense.org/) |
| `jetbrains-mono-400.woff2`, `jetbrains-mono-600.woff2` | JetBrains Mono | JetBrains | [OFL 1.1](https://openfontlicense.org/) |

Estão versionados no repositório de propósito: a regra do projeto é **nenhum CDN em
produção**, e uma unidade offshore trabalha sem rota para a internet. Fonte que só carrega
online é identidade visual que desaparece justamente onde o produto é usado.

Só o subconjunto latino foi embarcado (65 KB somados). Se algum dia o produto precisar de
cirílico ou vietnamita, os arquivos correspondentes entram aqui do mesmo jeito.
